# ☁️ AWS Hands-on: Serverless API & Data Streaming
Este repositório contém os códigos e instruções para o laboratório prático de construção de uma arquitetura moderna na AWS.

## 🎯 Objetivos do Curso
Ao final deste hands-on, você terá construído:

**API Serverless**: Uma API REST para leitura e escrita de arquivos (Upload/Download) usando API Gateway, Lambda e S3.

**Pipeline de Streaming**: Um fluxo de ingestão de dados em tempo real com transformação (ETL) usando Kinesis Data Streams, Data Firehose e Lambda.
